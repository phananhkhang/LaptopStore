# Tài nguyên ứng dụng

Owner A điều phối config; owner module chịu migration của mình. Giữ application.properties theo môi trường, không ghi secret. Flyway ở db/migration. static/templates chưa dùng cho React hoặc API.

Đọc [kiến trúc](../../../docs/architecture/README.md) và [kiểm thử/vận hành](../../../docs/architecture/09-testing-and-operation.md).
