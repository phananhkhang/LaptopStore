# Static resources

Thư mục dự phòng từ project gốc, owner A. Backend REST không đặt source React ở đây. File ở static có thể được phục vụ công khai: không đặt .env, DB dump hoặc upload không kiểm soát. Chỉ thêm asset khi có use case và cấu hình quyền/cache rõ.
